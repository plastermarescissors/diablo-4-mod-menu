## ✨ Features

### ESP
- Menu Overlay — toggle on-screen helper panel
- Range Notes — visualize attack ranges for study
- Cooldown Tracker — display skill timers
- Speed Notes — adjust overlay refresh for study (0.1x to 5x)

### Wallhack
- Loot Catalog — browse items, affixes, and rarity notes
- Build Notes — organize character builds
- HUD Improvements — improved buff and debuff visibility

### Aimbot
- Map Notes — segment study on any dungeon layout
- Route Planner — manually note paths mid-run
- Stash Buffer Notes — chain complex inventory moves in the menu
